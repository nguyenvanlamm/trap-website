02 / Give us a trail

Useful details
beat a long story.

You do not need to share your name, email address or any other identifier. These details help the maintainers understand a report without collecting anything automatically:

  1. Device and OS. Name the device family and operating-system version if you know it.
  2. App version. Include the app version/build if known.
  3. Reproduction steps. List the smallest sequence that makes the issue appear, including level or screen context.
  4. Observed and expected. Explain what happened and what you thought should happen instead.

Trap does not automatically collect device diagnostics through this website. If a log contains private data, remove it rather than attaching it.

03 / Before you file

Quick answers
for a cleaner report.

Is there a private support email?+

No email address is published as a Trap support contact. Use the public GitHub forms above and leave out sensitive information.

Do I need a GitHub account?+

Yes. GitHub requires an account to submit an issue. The account is for support communication only; Trap gameplay does not require an app account.

Can I send a private crash log?+

No automatic crash-log upload is provided here. Public reports should contain a redacted summary and reproduction steps, never passwords, personal data or sensitive logs.
